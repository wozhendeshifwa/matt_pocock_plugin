# 原生视觉采样：已观察事实与缺项

日期：2026-11-28。对应视觉基准采集票，使用 CUA 已有 MCP App 面板的只读 DOM 计算样式及原生窗口观察。

## 已取得的面板数据

- 当前聊天出现两个同名 MattSkillsDeck 面板。成功读取的面板 tab 2 显示看板、沙箱任务、设置、状态、运行五个页签，仓库链接为目标仓库。
- 面板内部视口为 500×822 CSS px，devicePixelRatio 为 1.5；这不是浏览器缩放为 150% 的独立证明。
- DOM 的 data-theme 为 dark；body 计算背景为 rgb(16,19,26)，文字 rgb(230,237,243)。顶层导航背景 rgb(22,24,29)，边框 rgb(42,45,53)。
- 首个导航按钮字体为系统无衬线 12px，圆角6px，高26.67px；搜索输入字体13.3333px、高29.33px、宽476px。body 与导航的 clientWidth/scrollWidth 均为500，此状态下未观察到它们横向溢出。
- 该面板三个内联 script 的文本长度分别为675、2114084、18584。与当前磁盘客户端2144549字符不同，说明这个面板不可直接用作当前磁盘版本的验收样本。尚不能据此判断缓存机制、另一面板或服务进程的具体责任。
- 通过页面控件成功进入设置页，观察到工作区后端总览、日志入口、更新失败提示及作者插件链接。未点击更新、导出、清空等动作。
