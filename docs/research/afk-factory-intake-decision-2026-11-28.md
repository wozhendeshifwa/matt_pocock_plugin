## 接单契约

一批确认的工单形成不可变接单快照：批次 ID、项目规范路径与仓库、用户确认依据和授权范围、工单 URL 与内容摘要、验收标准、排除项、原生依赖、已提交基线 SHA、检查命令、预估改动区域、模型/运行时限/现有费用边界、全机容量、优先级及明确允许的结果操作。补充材料和后续更正另记版本，不覆盖原确认事实。

每单必须同时满足：目标及验收可判断；无未解决的实质歧义；必要资料、工具和授权已具备；可从固定提交隔离运行；依赖可解析且无环；明确结果与检查证据位置；没有另一有效执行认领。缺项仅将该单和实际依赖者列为待补充，独立单继续。小型试点推荐每批2—3单、全机并发默认2，并受现有更低上限约束；不为试点改动用户全机设置。

用户工作区的未提交内容默认不进入任务。若工单依赖该内容，应先形成另行明确授权的提交/输入快照；不得偷偷 stash、提交或复制整个脏工作区。接单摘要明确列出已排除的未提交改动数量及影响。

当前连续执行授权允许本地图常规 AI 决策和本地图合规的提交/推送/合并；它不自动确认未来产品运行中的任意工单批次，也不改变产品首版“合并/发布由人确认”的边界。

## 调度与冲突

每次调度读取当前认领、依赖、输入版本和实际执行状态，再启动。候选必须属于确认批次且全部输入前置满足；外部阻塞单只有核实前置成果、基线和质量状态后才可接入。依赖关闭只是信号，不能用 issue closed 单独证明所需产物合格。

顺序采用用户显式优先级，其次解锁更多后继者，再按确认顺序稳定排序；同优先级先到先执行。重试进入原优先级队尾，不抢占已运行任务，避免故障单持续饿死其他单。新高优先级单也不得越过批次确认。

独立任务可并行，满足以下全部条件：各有独立执行目录和分支/结果；没有产物依赖；预计改动区域不交叉；没有共享可写配置、数据库、端口或原生 UI 验收资源。范围不明先按冲突处理。锁文件、共享入口、同一服务重启、同一桌面/UI 验收默认串行；单纯读取同一文件可并行。若执行中发现区域扩大或实际冲突，停在安全检查点，重核影响，只暂停相关任务；不得让两名执行者同时覆盖共享文件。

后继单要使用前驱结果时，由协调者在隔离集成分支按已记录顺序整合，跑必需检查并锁定新 SHA 后再启动后继；不要求先合并 main。冲突由主代理串行解决并重新检查、审查；实质范围改变须重新确认。最终面向用户的可审阅代码必须注明集成基线，不能只展示分散的各单成功。

## 认领、暂停、取消与恢复

“执行中”须有执行 ID、输入版本、隔离位置、拥有者和最后证据；issue assignee 只防止重复认领，不证明工作正在运行。启动回包丢失时用稳定操作 ID 查询原执行；未核实前禁止新建替代执行。现有 Sandcastle 单任务 token 幂等可复用，跨进程批次幂等仍待设计实现。

暂停分为排队暂停、运行中停止请求、等待用户/前置、状态待核实。运行中暂停只有达到安全检查点或确认执行终止才释放资源；未知状态保留槽位，不标成功、不自动重跑。局部暂停只传播给实际依赖者；整批暂停由明确整批指令触发。

取消排队单立即移出候选；运行中取消先请求停止并核实终止；保留代码、日志和检查证据。依赖取消单的任务改为前置取消，等待替代方案，不能自动删依赖开工。用户取消不等于允许清理结果或自动恢复。

中断恢复先读持久检查点，核对项目、输入版本、执行身份、真实遗留进程、结果 SHA 与授权。确认仍运行则重新观察；确认已停止才允许继续/重跑；无法确认则停该执行。明确人工暂停保持暂停，自动服务重连授权不覆盖人工暂停。重跑沿用原失败证据，建立新的尝试 ID，质量返工轮数不因会话重启或新尝试而归零；具体两轮规则由质量决策定义。

## 工单变化

每次启动及交接前比较工单内容摘要、依赖和目标基线。拼写、链接修复等不影响目标的更正可由 AI记录后接受；目标、验收、依赖、输入、费用/凭据权限或预估改动范围实质变化时冻结该单，列出差异与最小待确认项。变化后相关后继重核，独立单继续。不得将远端正文变化静默写入已运行输入；当前结果只能按原快照评估，并明确标注过期风险。

## 可操作验收场景

| 场景 | 期望证据与结果 |
| --- | --- |
| A依赖B，C独立；B缺凭据 | B等待用户，A等待B，C继续；不新增凭据或权限 |
| A/B均修改锁文件 | 串行且后单以已核实集成SHA开工；无并行覆盖 |
| 开始回包丢失，用户再次点击 | 查询同一执行ID，不出现第二执行；未知状态保留占槽 |
| 工单运行中新增验收 | 旧输入快照仍可追溯；该单冻结/安全停止，列出差异；C继续 |
| 用户取消A，B依赖A | A已终止才释放资源；B不会越过已取消依赖；结果不被清理 |
| 服务重启且有人工暂停单 | 暂停保持；运行项先核实，不把中断记作通过或新任务 |
| 两个单独通过但集成失败 | 批次仍未达可审阅集成标准，保留各单和集成证据 |
| 失败单持续返工，独立单排队 | 原优先级队尾排队且有轮次上限；独立单获得容量 |
| 用户源目录有无关修改 | 源目录未被更改；任务只用固定提交，并展示排除内容影响 |

这些是后续原型/实施的验收标准，本文件没有宣称已经通过。提示词版试点可人工/主代理记录这些字段和转换；持久性、并发互斥与崩溃后至多一次派发不能仅凭提示词承诺。
