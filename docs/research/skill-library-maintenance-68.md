# 限定技能库自动维护

## 生产接线与权限

`createOriginalHost` 启动时在后台执行一次检查，来源慢时只读看板与详情仍可读取，并显示 `checking`。使用前调用写类 RPC `skill.prepare`：它等待同一队列并再次检查。`skill.readDoc` 和 `chain` 不执行更新。真实 MCP 工具拒绝把维护请求投到 `deck_upstream_read`。

自动维护类别为 `skill-maintenance`，确认依据为此前授权的 `automatic-library-policy`，无需逐项更新确认；其他 Git/Issue 等写操作的原有审批要求不变。启动与使用前检查均记录脱敏审计，只有目标摘要，没有原始路径、URL、正文或凭据。普通 RPC 只能提供技能名；来源与目标不能从 UI 输入获得。

可信宿主通过 `skillHost.getUpdateBindings({projectRoot})` 提供既有绑定，每项为：`id`、`sourceId`、`projectRoot`、`kind`（`host` 或 `bundled`）、`manifestUrl`，以及宿主目标的 `targetRoot`。返回项目须真实路径匹配当前项目；重复 ID、重复或嵌套目标、冻结 vendor 目标均拒绝。首次绑定由宿主证明，已记录的来源身份不可静默切换。

本机当前 transport 没有可信来源绑定，因此生产返回 `source-unbound`，保留现有可读参考，不猜测 mattpocock/skills、FeatherHunter 或用户目录来源，不覆盖真实用户技能。该状态允许生成查证草稿，不等于依赖步骤已经可以执行。

## 绑定清单与维护结果

来源清单含 `sourceId`、`revision`、`skills`；每项技能含 `name` 及 `files`，每个文件含相对 `path`、相对资源 `url`、字节 `size` 和 `sha256`。仅允许插件既定 27 项、每技能最多 64 文件、单文件 200000 字节、总计 8 MiB。路径拒绝越界、Windows 特殊设备/别名和重复，资源保持清单所在目录及同源，拒绝重定向；支持已绑定本地文件、HTTPS 和本机回环 HTTP。

每次先读有界清单并核对完整本地文件集合与 hash，未变不请求正文；修订变化不掩盖内容相同，额外旧文件不被误报为完全一致。更新在同盘 staging 校验文件摘要、技能名、必要引用及可信工具核验后，才备份并切换。受管随包副本只写 `<dataRoot>/skill-library`，冻结 vendor 原件保持不变。宿主目标旁的 `.mattskills-maintenance` 保存锁、阶段记录和可恢复旧版；其他技能目录保持原样。

跨进程互斥通过原子发布完整 PID/token 所有权文件实现，活进程占用时返回 `busy`，死进程锁在受互斥保护的恢复路径接管。阶段 journal 在下一次准备时先恢复中断的替换；失败时尽量恢复全部已切换技能。无法核实的锁或损坏 journal 保守拒绝继续写，保留文件以便排查，不虚称自动恢复成功。备份和失败 staging 不自动删除。

结果区分 `source-unbound`、`binding-invalid`、`checking`、`updated`、`up-to-date`、`busy`、`check-failed` 和 `install-failed-no-usable-source`。每个受影响技能分别核验目标文件与完整冻结只读备用；安装失败但备用完整可用时不误报“无可用来源”。可读性、依赖工具可用性、来源修订一致性和宿主实际加载是不同事实；`actualLoad` 始终未知，更新成功不表示当前聊天已加载。

## 验证与限制

高层准备入口使用临时来源/目标：覆盖安装、升级备份、无变化时关闭正文源仍成功、hash/源失联失败保留、重复/错项目/嵌套绑定、路径与 junction 拒绝、原件及无关技能保留、受管随包副本、持久化中断状态恢复和完整冻结备用。

真实 `node-host` 子进程配合回环 HTTP，验证启动源请求被挂起时只读详情仍返回 `checking`，另进程准备被锁拒绝；放行后使用前检查与详情读取正确。关闭正文端点后继续检查不产生正文请求，随后升级遇到 503 保留旧版。审计覆盖启动与使用前类别及脱敏要求。真实 MCP/技能页验证新增端点为写、不能由普通 payload 选目标、无绑定如实返回。

基础使用前调用已接入真实客户端构建：技能请求进入当前聊天、新聊天或复制前等待 `skillPreparation` 桥接服务，后者使用写类 RPC 并在异步前后复核聊天和项目身份。状态结果保存在 `st.skillPreparation`，不包含规则全文。来源未绑定允许查证请求继续；技能已更新或检查失败需重新审阅时停止旧出口并提示，出口不追加或替换任何文本。React 按钮测试证明等待、触发及停止行为，桥接测试证明写路由和目标变化拒绝。

这些验证不安装本机用户技能，也不证明真实 Codex 宿主技能加载。来源状态详细进入可见草稿、所有三出口最终预览一致性和完整宿主验收由集成票继续完成。基础客户端触发不替代交互规格的可编辑预览与生命周期。
