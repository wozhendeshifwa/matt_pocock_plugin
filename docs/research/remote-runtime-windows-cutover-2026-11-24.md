## Windows 启动故障

使用无业务内容的 PowerShell 脚本进行本机对照。Node 以 `detached: true`、隐藏窗口、忽略标准流启动 Windows PowerShell 5 时，进程返回 0，脚本没有写出执行标记。去掉 `-WindowStyle Hidden` 后仍出现相同结果。去掉 `detached: true` 并保留隐藏窗口和忽略标准流，脚本写出了标记。

修复保留 `unref()` 和隐藏窗口，移除了启动 PowerShell 时的 `detached` 参数。启动器也会记录已派发的 PID，辅助事后排查。所有权验证仍需父进程创建时间、命令指纹与 Node 子进程关系。新回归在隔离项目中使用真实 PowerShell、固定包校验脚本和一个受控的 Node 子进程，验证成功连接、核对父子进程和正常停止。

针对这次修复运行的三项测试全部通过，覆盖原生 Windows 启动、迟到启动的清理与并发启动的防重放。另用临时 `.lnk`、与已安装登录项相同的 PowerShell 目标程序和窗口设置启动无业务脚本，Windows Shell 成功执行并写出了标记。
