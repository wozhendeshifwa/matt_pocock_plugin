## Spec

初次发现 1 项代码问题，最高 P2：

修复与证据：

- 已在公开 `listIssues` 外部 API 夹具先复现失败（应有原生 #99，实际为空），再通过修复：主池已有子票复用完整同身份元数据；池外子票独立分页读原生 `dependencies/blocked_by`。REST 降级或摘要与已有明细矛盾时也重新核对。明确原生总依赖数为零才允许跳过空集合读取。

- 开放阻塞票即使在有界池外也会限制执行；独立读回真实关闭的阻塞票后沿用完成门槛。依赖明细、读取恢复及嵌套关系进入快照版本，避免恢复后 304 保留旧门槛。
