# MattSkillsDeck 侧栏原型

重新启动 Codex 后，从右上角 `+` 打开 **MattSkillsDeck**。点一个打开的 Issue，核对派发预览，再点「确认并开始」。任务进度会自动刷新。已有的 `deck-sidebar-probe` 注册名继续使用。

本原型绑定 `wozhendeshifwa/matt_pocock_plugin`。派发通过独立的 `codex exec` 会话做只读诊断，任务记录保存在用户目录的 `.matt-skills-deck` 下。重开面板可以读取同一份记录。

可为不同的 MCP 注册分别配置 `DECK_PROJECT_ROOT`（本地项目路径）和 `DECK_REPO`（GitHub 的 `owner/repo`）。两项需要一起设置。记录按仓库和解析后的本地项目路径隔离，默认项目继续读取原有记录。派发预览显示实际目标。当前使用固定绑定，自动跟随仍待客户端上下文验证。

验收时使用一条专门的打开状态 Issue，确认派发后仍留在原聊天，等待看到任务结果，再切换到同项目另一个聊天检查记录是否仍可见。自动识别当前项目和跨项目隔离属于后续验收。
