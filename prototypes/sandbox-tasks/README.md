# 本机沙箱任务

按 Sandcastle 接入规划的接入、交互与验收决策实现。此模块只走本地：侧栏 App 工具 → 可信项目解析 → 本机用户私有命名管道 → SQLite 调度器 → 独立执行器 → Docker/Sandcastle/Codex。旧草稿按钮、远程组件和 provider 配置不参与任务执行。

## 生命周期与数据

`manager.mjs` 持有持久任务、预览确认与启动防重记录，统一控制整机并发。确认启动前固定提交；排队不计入任务运行时限。`engine.mjs` 给每项任务建立独立 clone 和 Git 数据，并只访问所属目录。`worker.mjs` 独立于面板与调度器连接运行，保存心跳、日志、结果及检查退出码；取消先请求停止，核实容器已停止后才发布终态。

组件恢复后暂停旧队列，先核对旧执行与容器，未知状态不重跑。连接异常不等同任务失败。失败、取消和中断保留现场。重新运行必须再次预览确认，默认沿用原描述与提交、创建新任务及分支。

容器检查拿不到正常退出状态或运行环境被中断时，记录为“检查未知／执行中断”，保留原始退出码；正常检查失败另行记录。较早版本将关机异常写成检查失败的记录，会保留原始结果并先核实停止，再保存状态纠正记录。失败/取消/中断不自动删除工作树，明确清理后才移除所属容器和代码现场。登录自启的是本机管理组件，执行和遗留容器核对仍要求Docker引擎可连接。

仅完成且有改动的结果可以预览合入当前目标分支；可以先在原 Git 界面切换目标，再重新预览。未通过/未运行检查需额外确认。目标有未提交或未跟踪内容、目标提交变化或结果变化均拒绝旧确认。冲突保留结果，目标保留 Git 的冲突状态供用户处理；不自动解冲突或推送。清理必须预览范围；运行中/待核实任务不可清理，源项目与认证目录不在清理范围。

## 本地配置与启动

先完成 Docker、ChatGPT 专用登录及隔离门槛，核验非 root 镜像与可用模型。在本模块安装锁定依赖，使用 `configure.mjs --apply --image <verified image> --auth <dedicated auth directory> --model <verified model> --models <verified model list> --startup` 配置本机后台。该命令仅供本机操作，不作为 MCP 参数开放。

配置和令牌默认写入用户 Codex 目录内的 `sandbox-tasks`，Windows ACL 限定本用户、SYSTEM 与管理员。覆盖配置前生成备份。`--startup` 创建当前用户登录启动入口和开始菜单入口，不修改 provider、远程配对或其他 MCP 配置。后台使用隐藏进程，关闭面板或 Codex不停止任务。侧栏“预览退出后台”展示全机受影响任务，再确认停止并退出；未核实执行停止时不报告成功。

侧栏集成使用 App-only 的 `deck_sandbox_read`/`deck_sandbox_write`，每次从宿主 metadata 解析当前项目并核对 expectedThreadId，拒绝客户端提供项目路径来改变作用域；不把启动写操作放到 readOnly 工具中。命名管道请求另有本机私有令牌。正式传输没有监听 HTTP 端口；`preview.mjs` 仅用于一个指定夹具项目的本地开发验收。

认证缓存不在镜像或项目仓库中，不能提交、上传或贴入 issue。详情和日志只在本地查看。模型必须在本地已核验列表内，失败不会静默换模型、认证或收费路径。

## 验证与范围

运行 `npm test`。测试覆盖真实 SQLite 恢复、防重、并发、取消竞态、私有IPC授权及单实例、项目隔离、Windows 文件占用、真实 Git 目标保护、宿主Git扩展命令隔离和界面确认/XSS边界。启动回执缺失时保持待核实，不将缺少状态文件当成执行已经结束。

`acceptance.mjs <new disposable directory> <dedicated auth directory>` 运行真实模型与 Docker、后台进程重启、检查、结果合入和运行取消，不可指向用户日常项目。需要已验证镜像及账户额度。它会将详细本机证据写在指定目录，不上传。

`concurrency-acceptance.mjs <new disposable directory>` 复用本机已配置环境，验证真实二并发/第三项排队、队列基线固定以及检查通过/失败/未运行三类证据。仅接受尚不存在的新目录。

构建/独立浏览器检查不等同真实 Codex 原生侧栏验收。运行中的 MCP 服务加载新侧栏资源需要宿主重新连接；完成之前不将正式实施票标为全部验收通过。完整发布还须按验收决策逐项核对实际安装、登录自启、关闭/重开、异常恢复、超时、清理与原入口回归。
